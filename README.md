# Idle House Production Game

## 🎮 Jogo Idle de Produção de Casas Futurísticas

Um jogo idle 3D desenvolvido como aplicação web, onde o jogador constrói um império habitacional do futuro através do cosmos.

### 🚀 Características

- **Interface 3D**: Ambiente tridimensional interativo com Three.js
- **Progressão Idle**: Continue ganhando recursos mesmo offline
- **Materiais Cósmicos**: Explore planetas distantes por materiais únicos
- **Sistema de Upgrades**: Melhore sua produção e eficiência
- **Design Futurístico**: Interface cyberpunk com efeitos visuais

### 🏭 Centrais de Comando

1. **Central de Produção** - Construa casas manualmente e gerencie a linha de produção
2. **Centro de Controle** - Adquira upgrades e melhorias para otimizar operações  
3. **Estações Planetárias** - Desbloqueie novos planetas e materiais exóticos

### 🌌 Materiais & Planetas

- **Terra**: Basic Concrete (material inicial)
- **Marte**: Steel Frame (2.5x valor)
- **Europa**: Crystal Composite (10x valor)
- **Kepler-442b**: Quantum Material (50x valor)

### 🎯 Como Jogar

1. Comece com ₢100 e materiais básicos
2. Construa casas manualmente para ganhar dinheiro
3. Invista em upgrades para automatizar e acelerar produção
4. Desbloqueie novos planetas com materiais valiosos
5. Expanda seu império habitacional pelo universo!

### 💻 Tecnologias

- **Backend**: FastAPI + MongoDB
- **Frontend**: React + Three.js
- **Estilo**: Tailwind CSS + Design Cyberpunk
